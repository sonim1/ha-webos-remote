# Roadmap

Current functionality is described in the [README](../README.md). Future releases use semantic versioning.

## Next priorities

- Visual dashboard configuration editor and automatic TV discovery.
- Better pairing diagnostics and recovery.
- Reconnection after TV standby or Wi-Fi interruptions; long-running pointer tests.
- TV state and volume level indicators.
- Broader model and application testing for Page Up/Down, scrolling, Gallery+ and text input.
- Simulated webOS integration tests and accessibility improvements.

## Additional features

- Multiple TV profiles and configurable Quick Apps.
- Custom layouts, themes and fullscreen mode.
- Korean/English UI translations and mobile interaction improvements.
- WSS proxy guidance, scoped tokens and rate limiting.
- Screenshot regression tests and HACS default catalog submission.

Track upstream resolution of the installed sqlitedict [dependency advisory](../SECURITY.md#dependency-advisory). Live input remains experimental until application compatibility is better established.
