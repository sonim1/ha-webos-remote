# Contributing

Thank you for helping with LG webOS Remote for Home Assistant.

1. Open an issue before large feature work. Include a device model, firmware version and **sanitized** logs.
2. Keep the project independently authored. **Do not copy source from the CC BY-NC-ND Lovelace Touchpad Card or Pointer Bridge projects.**
3. Use Node.js 22+ and Python 3.13+. Create and activate `.venv`, then run `python -m pip install -r lg_webos_remote/requirements.txt pyyaml`. Run `npm run build`, `npm run verify`, and `python3 -m py_compile lg_webos_remote/*.py` before opening a pull request.
4. Preserve MIT and third-party license notices, add regression tests for any protocol changes, and avoid dependencies without verifying their licensing.
5. Never commit card YAML tokens, TV pairing credentials, MAC addresses, public endpoints or Home Assistant backups.
6. Prefer backward-compatible UI/card YAML changes and avoid breaking add-on configuration keys.

Releases are generated by tagging the same version as `VERSION`, for example `v1.0.0`; the workflow uploads the dashboard JavaScript and source ZIP to a GitHub release.

Tests exercise the Bridge over a real loopback WebSocket with synthetic settings. TV control and WOL network side effects are mocked. Preserve the independent pointer connection and test cancellation cleanup. Keep hardware-only claims separate from automated results. ZIP packaging includes tracked Git files only; inspect the staged paths before packaging.
